# Content needed (source-checked, from Duet)

Nothing here is to be invented. Each item says how many, what kind and which fields.

## 1. Country areas (blocks close pairs in Bigger country?, size prompts in Fathoms, Stamps and Voyage)
- **How many:** all 195 countries in the country pack (193 UN members, Vatican City, Palestine as the pack lists them).
- **Fields:** country name exactly as in `data/countries.txt`; area in km2; which definition (land or total: one definition for every row); source and year.

More items will be added by the never-the-same-twice count (P3): each game's pool size and how many days it lasts.
